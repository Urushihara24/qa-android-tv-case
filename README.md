# Тестирование приложения слайд-шоу для Android TV

Кейс из реальной работы: ручное тестирование клиентского приложения
для Android TV (слайд-шоу, кэширование, оффлайн с USB, подборки, потоки).
Автор: Всеволод.

## Что внутри
- docs/REPORT.md — отчёт: результаты по сценариям (OK/FAIL/NOTE), выводы, рекомендации.
- test_cases/TEST_CASES.md — прогоны; каждый кейс ссылается на баг по ID.
- bugs/BUG_REPORT.md — баги по сценариям: шаги, факт, ожидание, серьёзность, приоритет.
- docs/IMPROVEMENTS.md — предложения по улучшению (не дефекты).
- docs/LEGEND.md — легенда статусов и серьёзностей.

## Как читать
Кейсы и баги связаны по ID: по таблице кейсов видно, какой прогон какой баг
породил, по багам — что сломалось и как должно было быть. Оффлайн и онлайн
поведение сверял между собой, чтобы отделить дефекты кэша и чтения с USB
от дефектов самих слайдов. Баги разведены по сценариям, чтобы разработчик
смотрел только свои видео и свои артефакты.
