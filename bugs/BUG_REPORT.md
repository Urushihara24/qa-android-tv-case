# Баг-репорты (по сценариям)

### BUG-001 — Зависания приложения

- Сценарий 1 · 0011808 · Major / High · Open
- Шаги: запустить 0011808 (с кешем); воспроизводить слайд-шоу.
- Факт: зависания (00:35, 02:20); лаг приложения (04:14).
- Ожидалось: воспроизведение без зависаний и лагов.

### BUG-002 — Лаги/фризы при переходе между слайдами

- Сценарий 1 · 0011808, 74367 (su) · Major / High · Open
- Шаги: переключать слайды на 0011808 и 74367.
- Факт: лаги переходов на 0011808; на 74367 (02:10–02:19).
- Ожидалось: плавные переходы без лагов.

### BUG-003 — Белая область вместо изображения (недогрузка)

- Сценарий 1 · 0011810 · Major / High · Open
- Шаги: воспроизводить 0011810; наблюдать загрузку изображений.
- Факт: белая область по центру (03:48); прогрузка частями с белой областью (05:30).
- Ожидалось: изображения загружаются полностью в рамках тайминга слайда.

### BUG-004 — Остаточные артефакты старого слайда при переходах

### BUG-005 — Частичная/постепенная загрузка слайда

### BUG-017 — Оффлайн: СШ воспроизводятся только из служебной папки кеша на флешке; нет подсказки пути

- Сценарий 3 · 0011946, 0011961 · Major / High · Open
- Шаги: разместить файлы вне служебной папки кеша (в другой папке/в корне) — нажать USB; затем положить в служебную папку кеша и повторить.
- Факт: вне папки кеша — «слайд-шоу не найдены»; из папки кеша — запускается. В UI нет подсказки пути, поиск методом тыка.
- Ожидалось: СШ находятся с USB независимо от папки, либо путь явно указан в UI.
